Java Core Application & Source Architecture

How to clone, compile, and run the native Java 25 console platform locally.

1. Clone the GitHub Repository

git clone https://github.com/SriRam743/SmartFactory.git
cd SmartFactory

2. Compile via Command Line

javac -d bin -sourcepath src src/app/SmartFactoryApp.java

3. Execute the 34-Option Interactive Console

java -cp bin app.SmartFactoryApp

Package Organization

src/app/ Main CLI entrypoint (`SmartFactoryApp.java`)
src/data/ CSV parser & data streaming loader
src/factory/ KMP, Z-Algorithm, Aho-Corasick
src/reports/ Suffix Array, SA-IS, Kasai LCP
src/optimization/ Levenshtein, Damerau, Matrix Chain DP
src/flow/ Ford-Fulkerson, Edmonds-Karp, Dinic
src/np/ 3-SAT DPLL, Clique, Vertex Cover 2-Approx
src/parallel/ Blelloch scan, Miller-Rabin, Brent's speedup
dataset/ smart_factory_datset.csv (10,050 records)
